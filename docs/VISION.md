# 续行愿景锚点（VISION）

> 依据：《续行｜最终产品全景设计蓝图》v1.0（终局设计）+ D1–D9 定版决策。所有批次、评审、派活以此为准；与此冲突的做法即偏离，须显式上报，不得静默绕行。

## 终局愿景（一句话）
续行是一个**以目标与结果为中心**的协作执行系统：用户给出目标，系统维护一张**动态任务图**，**人与 AI Agent 作为对等执行者**共同推进，任务图随执行实时演化（分解、阻塞、改派、验收），而不是一张静态待办清单。

## 四条不变原则
1. **事件溯源确定性内核是唯一真相源**：一切状态由事件落账后投影派生；可审计、可重放、可对账。UI 与任何执行者都不得有绕过事件流的私有状态。
2. **智能层只提议，内核裁决**：AI 只能产出提议（分解、指派、状态迁移建议），由内核按冻结契约校验后才落账。AI 永远不直接改状态。
3. **执行可插拔**：执行者是可替换的适配层（真人、本地节点、云端 Agent、未来的新平台），内核语义不依赖任何单一执行器。
4. **产品力是验收项**：交互契约先行、投影一致性可测、功能覆盖可追溯（D9）；旅程跑通 + 有质感与"演示级好看"同为目标，后者按 D8 不在本阶段范围但方向不变。

## 偏离红线（出现即停并上报）
- 把续行做成静态任务清单/看板（丢掉动态任务图与演化语义）。
- 任何路径绕过内核事件流直接写状态（包括为赶进度在 UI 或执行器里存私有状态）。
- 为单个批次的便利修改冻结契约语义而不走 contract-review。
- 执行器产出未经核实直接合入主线。
